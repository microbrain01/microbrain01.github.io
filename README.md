# microbrain Portfolio

TinyML(임베디드 기기에서 동작하는 경량 AI)을 공부하는 microbrain의 포트폴리오 저장소입니다.

## 구성

- `index.html`: 단일 파일 정적 페이지입니다. HTML5와 순수 CSS만 사용하며 외부 의존성이 없습니다.
- `resume.pdf`: 다운로드용 이력서입니다. (1페이지)

## 소개

- **관심 분야:** TinyML, 임베디드 시스템, Edge AI
- **학교:** 부산대학교 (재학 중)

## 대표 프로젝트: 저전력 오프라인 소리 인식 장치

- **상태:** 계획 단계
- **문제 정의:** 서버 없이 기기 안에서 소리를 인식해 전력, 지연, 개인 정보 전송 문제를 줄입니다.
- **역할:** 기획, 모델 학습, 펌웨어 개발
- **기술:** ESP32, TensorFlow Lite for Microcontrollers, C/C++, Python
- **목표 결과:** 정확도 90% 이상, 모델 크기 100KB 이하, 추론 지연 100ms 이하
- **데모:** 프로토타입 완성 후 추가할 예정입니다.
- **소스 코드:** 이 저장소입니다. 프로젝트 코드는 구현 후 별도 저장소로 추가할 예정입니다.

## 배포

GitHub Pages(브랜치 배포)로 `main` 브랜치의 루트(`/`)를 서빙합니다.
